# Clean-up pass, 2026-11-20

The owner's rule for this pass: nothing is deleted as "dead" without proof that it is not reachable
and never runs. No gameplay, tuning, art or copy changed; no dependency changed.

## How dead code was found

Three maps, all taken on `migrate/fizlet-org` at 63a2a63, none of their tooling added to the repo:

1. **Unused names.** `tsc --noEmit --noUnusedLocals --noUnusedParameters` (the repo's own TypeScript)
   for locals and imports, and a script that lists every `export` in `src/` whose name appears in no
   other file of `src/`, `tests/` or `site/src/`. (`npx knip` was the first choice; this session was
   not allowed to download it.)
2. **What runs (JavaScript).** V8 coverage, merged: `NODE_V8_COVERAGE` over `npm test` (60 tests, which
   import `src/*.ts` directly) and Playwright `page.coverage.startJSCoverage` over `test:settle` and
   all 15 files of `test:browser` (32 page dumps, an unminified build so functions keep their names).
   674 functions of the game's own code ran or were seen; 59 never ran in a browser, 40 of them named.
3. **What matches (CSS).** The game's styles live in a shadow root, where Chromium's CSS coverage
   reports nothing, so a probe in every test page asked, on every DOM change, which selectors of
   `src/game.css` matched an element (hover, focus and pseudo-elements stripped first). Run over
   `test:site` (1440 and 390, dark and light), `test:settle` and the 15 browser files.

Dead means: no caller in the import graph **and** zero executions. One without the other stayed.

## What stayed, on purpose

- **Never ran, but reachable.** The rollback's counters (`stalls`, `waits`, `resims`, `deepest`,
  `lost`, `away`, `dropped`, `steps`, `delay`, `resimMs`, `resimTotal`): the link's public readout.
  `scene.poster()` (the landing page's still for reduced motion), `scene.retheme()` (a theme change
  on the page), the mute key's `toggle`, `restart` (AGAIN and RETRY on the run's card), the gamepad
  and online paths' closers, the garage's RANDOM (`pickOwned`), `game.exportCode()`. A person can
  reach every one; the suites just do not press them. They are gaps in the tests, not dead code.
- **Ran only in the unit suite** (`burn`, `derail`, `knock`, `truckBust`, `targetAt`, `inGrab`,
  `reachCount`…): game rules the browser runs did not happen to hit.
- **`RIVAL_WHAT`** (`src/monster.ts`): only `tests/profile.test.mjs` reads it now (it guards the rivals'
  descriptions). Kept with its test.
- **`W_THOOM`** (`src/scene.ts`): unused, but it is index 13 in a numbered table of sounds; a hole in
  the numbering would be worse than the name.
- **`for (const s of [-1, 1]) { … void s }`** (`src/monster.ts`, the CIRCUIT pattern): the loop draws
  the same three boxes twice. Removing it would change what the diorama holds (art), so it stayed;
  it is worth a look by whoever owns the rig.
- **Exports used only inside their own file** (`SHAKE_T`, `HITS_CRACK`, `WALLX`, `DROP_HOLD`, `FWD_Z`,
  `B_PUNCH`, `MAX_HP`, `GROUND_R`, `AI_POWER`, `P_WALK`, four option types): harmless, free in the
  bundle, and part of how the modules document their numbers.
- **No stale assets or fixtures.** `tests/fixtures/page.html`, `tests/room-server.mjs`, `tests/gc.mjs`,
  `scripts/shots.mjs` and both site images are all read by a test, a script or a page.
- **No commented-out code and no debug switch left on** were found (`LAYERS_DEBUG` and `SHOTS` are
  off unless set).
- **Every CSS rule.** Of the 151 selectors in `src/game.css`, 150 matched an element somewhere in the
  suites (85 page dumps). The one that did not, `.cs .cs-story .cs-note`, is the title's note line,
  which shows when the title is opened with a note still set (`game.show("menu")` from the garage):
  reachable, so it stayed. The garage's own rules are replaced, not cleaned, in the store change
  that follows this one.
- **Tidying by taste** (renames, named constants for repeated numbers in `round.ts` and `scene.ts`):
  not done in this pass. The numbers there are tuning, each already commented where it is set, and
  moving them risks the byte-for-byte determinism the sync tests check, for no measured gain.
